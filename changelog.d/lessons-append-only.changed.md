Lesson storage is append-only: a `versions` log (one record per changed lesson per write) and a `retrievals` log (one event per injection), from which usage strength is replayed at start. A retrieval turn now writes ~0.3 KB regardless of library size instead of re-snapshotting the whole library (~430 KB per turn at 1,000 lessons). Existing stores migrate on first start, keeping usage as a baseline event and leaving the old snapshot untouched. The shared `lessons.json` holds content only and is no longer rewritten on retrieval; usage is per agent. Retrieval's BM25 uses an incrementally maintained inverted index, and document embeddings persist in `$DATA_DIR/retrieval-cache/`, so restarts don't re-embed the library.
